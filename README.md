# LCCR - Institution Management System (IMS)

An integrated Institution Management System for LCCR built on CodeIgniter.

## Features
- Student profiling and enrollment management
- Grades, promotional reports, and transcripts
- Billing, fee management, and cashiering
- Faculty evaluation and scheduling
- Alumni tracker and reports
- User management and role-based access control

## Requirements
- PHP 7.4+ / PHP 8.x
- MySQL / MariaDB
- Apache with `mod_rewrite` enabled
- Composer

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/mssd-devs/lccr-ims.git
   ```
2. Configure database credentials in `application/config/database.php`.
3. Set base URL in `application/config/config.php`.
4. Install dependencies:
   ```bash
   composer install
   ```
